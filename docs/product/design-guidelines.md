# 设计规范

Agent Workbench 采用 Ant Design 风格，定位为高频使用的工作台，而不是营销页。界面应克制、信息密度适中、操作路径稳定。

## 布局

- 桌面端使用左侧导航 + 顶部工具栏 + 内容区。
- 移动端侧边栏收起后，顶部提供页面选择器。
- 页面内容优先使用网格和列表组织，不做大面积装饰性模块。
- 卡片用于单个信息组、列表项或工具面板，避免为了装饰嵌套卡片。

## 组件

- 主操作使用 `Button type="primary"`。
- 二级操作使用默认按钮或文本按钮。
- 状态使用 `Tag`、`Badge`、`Progress` 和 `Steps`。
- 表单使用垂直布局，移动端字段单列。
- 数字概览使用 `Statistic`。
- 工作流使用 DAG layer 卡片表达依赖层级。

## 响应式

- Header 操作区必须允许换行。
- 表格在移动端使用横向滚动容器，不能撑破页面。
- 长标题、路径、环境变量名、capability 名称需要支持换行。
- Drawer、Modal 和 Form 的两列布局在小屏切换为单列。
- 移动端首屏应优先保留导航、搜索和主要操作。

## 可访问性

- 可交互元素需要保留清晰焦点态。
- 输入框 placeholder 使用简短示例或动作提示，并以省略号收尾。
- 不用颜色作为唯一状态表达，状态文字和颜色同时出现。
- 文本不能遮挡按钮、表格列或后续内容。

## 视觉语言

- 主色沿用 Ant Design 蓝色。
- 背景使用浅灰，内容面板使用白色。
- 圆角保持 8px 或更小，避免过度柔和。
- 字体层级按工作台场景控制，不使用过大的英雄标题。
- 装饰性渐变和大面积插画只在产物预览等特定场景使用。
