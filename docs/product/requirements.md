# 需求说明

## 范围

Agent Workbench 的第一阶段目标是完成本地单用户工作台闭环：用户可以创建任务、配置 Agent 与 Team、绑定知识和工具、审批高风险调用、运行工作流，并管理交付产物。

## 功能需求

### 任务与运行

- 支持创建任务，任务目标可指向 Agent、Agent Team 或 Workflow Plugin。
- 支持任务状态流转：排队、待审批、运行中、暂停、完成、失败、取消。
- 支持运行事件展示，包括历史事件读取和实时事件订阅。

### Agent 与 Team

- 支持创建 Agent，并维护 runtime、模型、系统提示词、skills、知识范围和权限策略。
- 支持创建 Agent Team，并按成员顺序串行执行。
- Agent Team 运行时需要生成可追踪事件。

### Skills 与 Plugins

- 支持扫描本地 `skills/*/SKILL.md`。
- 支持扫描 `plugins/*/plugin.json` 与对应 `SKILL.md`。
- Plugin 启动前需要展示 capabilities，并对高风险能力创建审批。

### 知识库

- 支持新增知识条目。
- 支持 SOP、品牌、平台规则、决策、代码文档等类型。
- 支持标签和团队/项目可见范围。

### MCP / CLI

- 支持登记 MCP server 和 CLI command。
- 支持连接器自检和试运行。
- 低风险 CLI 可直接执行。
- 中高风险 MCP / CLI 调用进入审批队列。

### Workflow

- 支持一句话生成工作流草案。
- 支持 DAG 预览、模板套用、保存、重新打开。
- 支持 YAML 导入导出。
- 支持完整运行、指定 step 重跑和带 feedback 返工。

### Artifact

- 支持登记任务或工作流产物。
- 支持查看内容、下载、追加版本和批量导出 manifest。
- 产物需要记录来源、路径、摘要、版本和更新时间。

### Secret 与权限

- 模型 API Key 保存于本机权限受限的凭据文件，不写入 SQLite 或接口响应。
- 设置页需要展示本地团队权限矩阵。
- 风险等级必须影响执行路径和审批策略。

## 非功能需求

- 本地优先：核心数据保存在 SQLite 或浏览器本地存储。
- 可离线演示：API 不可用时能进入静态本地模式。
- 可审计：任务、审批、连接器调用和产物生成需要保留事件记录。
- 可维护：产品、需求、架构、设计和技术文档分层存放。
- UI 一致：页面遵循 Ant Design 风格，支持桌面和移动宽度。

## 暂不包含

- 多用户登录和远程团队空间。
- 生产级分布式任务队列。
- 云端 Secret 托管。
- 远程 MCP HTTP 调用的完整执行链路。
- Artifact 全文检索和外部对象存储。
